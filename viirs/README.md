## VIIRS Satellite Data Analysis Suite

This project offers a number of tools designed for the analysis and processing of data sourced from the 
NASA and NOAA Visible Infrared Imaging Radiometer Suite (VIIRS) instruments.

VIIRS, aboard the Suomi National Polar-orbiting Partnership (Suomi NPP) and NOAA-20 satellites, provides high-resolution data crucial
for monitoring marine and inland water bodies.
